# Database Command References

This directory contains practical command and SQL references for Module 09. Use disposable local databases or approved development environments for exercises.

## Lessons

- [130 — Database Fundamentals](130-database-fundamentals.md)

## General Safety Notes

- Confirm the target database and environment before running commands.
- Treat SQL that creates, modifies, or deletes data as state-changing.
- Use parameterized queries in application code rather than concatenating untrusted input into SQL.
- Do not run exploratory or destructive commands against production databases.
- Keep credentials and sensitive query results out of source control and shared logs.
