# Diagram 114 — HTTP/3 Encapsulation Stack

```text
+-----------------------------------+
| IP Header                         |
|                                   |
| +-------------------------------+ |
| | UDP Header                    | |
| |                               | |
| | +---------------------------+ | |
| | | QUIC Packet               | | |
| | |                           | | |
| | | +-----------------------+ | | |
| | | | QUIC STREAM frame     | | | |
| | | |                       | | | |
| | | | +-------------------+ | | | |
| | | | | HTTP/3 frame      | | | | |
| | | | |                   | | | | |
| | | | | QPACK data        | | | | |
| | | | +-------------------+ | | | |
| | | +-----------------------+ | | |
| | +---------------------------+ | |
| +-------------------------------+ |
+-----------------------------------+
```

Each layer encapsulates the data from the layer above it and adds protocol-specific metadata.
